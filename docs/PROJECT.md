# Project: Image Upload, Crop & Preview (React Hook Form)
Mục tiêu: form dùng react-hook-form cho phép upload ảnh, crop 400x400 và xem trước.
Stack: Vite + React + JavaScript, react-hook-form v7, react-easy-crop, Tailwind CSS v4.
Chạy: npm run dev | Build: npm run build | Lint: npm run lint
Môi trường: macOS, Node 18+.
Cấu trúc: xem AGENTS.md và docs/.
